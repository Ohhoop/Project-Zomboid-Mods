# Project Zomboid Mods

Showcase of my Project Zomboid mods for Build 42. Each mod lives in its own repository.

| Mod | Description | GitHub | Steam |
|---|---|---|---|
| Quick Restart | Restart in a fresh world or respawn in the same one with your original character, straight from the death screen. | [Repository](https://github.com/Ohhoop/Quick-Restart) | [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3699503439) |
| Tile Doctor | Development and debugging tool to inspect the tiles around you and remove or rebuild broken objects. | [Repository](https://github.com/Ohhoop/Tile-Doctor) | Coming soon |
| Inventory Doctor | Development and debugging tool to inspect an inventory, including every bag, and delete broken items, for your own character or any online player as an admin. | [Repository](https://github.com/Ohhoop/Inventory-Doctor) | Coming soon |
